Connect your Supabase project

This account portal needs a Supabase project. Setup is not complete until the schema is installed and the project credentials are configured.

  1. Run database/supabase_marketplace.sql in your Supabase SQL Editor.
  2. Copy the project URL and public anon/publishable key into frontend/supabase-config.js.
  3. To appoint an administrator, sign up for an account first, then set its profile role to admin in Supabase SQL Editor. Never put a service-role key in the frontend.
